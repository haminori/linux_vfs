# VFS Shell Emulator — Этап 1: REPL

Вариант задания №19. Минимальный прототип эмулятора командной строки
UNIX-подобной ОС: графический интерфейс, парсер аргументов в
кавычках, команды-заглушки `ls`/`cd`, команда `exit`, сообщения об
ошибках. Большинство функций пока представляют собой заглушки —
полноценная VFS, конфигурация через параметры запуска и остальные
команды появятся на следующих этапах.

## Структура репозитория

```
src/vfs_shell/   исходный код эмулятора (demo.py — генерация транскрипта)
tests/           модульные тесты (pytest)
demo_logs/       пример работы прототипа в интерактивном режиме
run.sh           точка запуска
```

## Требования и как они реализованы

1. **Графический интерфейс (GUI).** Реализован на Tkinter
   (`src/vfs_shell/gui.py`): окно с полем вывода и строкой ввода
   команд, имитирующее терминал.
2. **Заголовок окна содержит имя VFS.** На этом этапе имя VFS ещё не
   настраивается параметрами (это Этап 2), поэтому используется
   константа `VFS_NAME` в `gui.py`, которая попадает в заголовок окна
   в виде `VFS Shell — <имя VFS>`.
3. **Парсер аргументов в кавычках.** `src/vfs_shell/parser.py`
   использует `shlex.split(..., posix=True)`, что корректно
   разбивает строку `cp "my file.txt" dest` на токены с учётом
   одинарных и двойных кавычек.
4. **Сообщение об ошибке выполнения команд.** Диспетчер
   `src/vfs_shell/shell.py` сообщает как о неизвестной команде, так и
   о неверных аргументах конкретной команды (например, `cd` без
   аргумента или с двумя аргументами).
5. **Команды-заглушки `ls`, `cd`.** Реализованы в
   `src/vfs_shell/commands.py`: они не работают с реальной файловой
   системой, а просто выводят своё имя и полученные аргументы —
   это подтверждает, что парсер и диспетчер работают правильно.
6. **Команда `exit`.** Завершает работу эмулятора (закрывает окно
   GUI).
7. **Демонстрация в интерактивном режиме.** См. раздел
   «Демонстрация» ниже и файл `demo_logs/stage1_demo.log`.
8. **Коммит.** Результат этапа сохранён отдельным коммитом в формате
   Conventional/Scoped Commits: `feat(stage1): ...`.

## Установка и запуск

Требуется Python 3.10+ с модулем `tkinter` (входит в стандартную
поставку Python; при установке на Windows с python.org — компонент
"tcl/tk and IDLE").

```bash
./run.sh
```

или напрямую:

```bash
PYTHONPATH=src python3 -m vfs_shell.main
```

В открывшемся окне можно вводить команды, например:

```
ls -la "my folder"
cd /home
frobnicate
exit
```

## Демонстрация

Так как в среде разработки не всегда доступен дисплей для реального
GUI-окна, в модуле `vfs_shell.demo` вынесена та же логика диалога
"$ команда / результат", которую показывает GUI (`Shell.execute` +
форматирование вывода). Файл `demo_logs/stage1_demo.log` —
зафиксированный транскрипт демонстрации всей функциональности этапа,
включая обработку ошибок:

```bash
PYTHONPATH=src python3 -m vfs_shell.demo
```
